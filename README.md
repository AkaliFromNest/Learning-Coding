# Learning-Coding

Welcome! This repository documents my journey learning how to code, starting from scratch (or refreshing what I once knew) and progressing through several programming languages, from easiest to most complex.

## Why this repo exists

I created this space to track my own progress, keep notes I can look back on, and hopefully help anyone else who's starting out and wants to see a real, honest learning path — including the mistakes and the "aha" moments along the way.

## Languages covered (in learning order)

1. **Python** — fundamentals, control structures, functions, and beyond
2. **Ruby** — coming next
3. **Go (Golang)** — coming next
4. **Rust** — ownership, structs, enums, and systems programming basics
5. **C++** — the final challenge

## Structure

Each language has its own folder with exercises, small projects, and notes:

├── Python/
├── Ruby/
├── Go/
├── Rust/
├── C++/

Inside each folder, files are organized by topic (variables, control flow, functions, etc.), and a `README.md` (when available) explains what each file covers.

## Goal

By the end of this journey, I want to be comfortable enough in each of these languages to build small real projects — and have a clear, organized record of how I got there.

Feel free to explore, and if you're learning too — good luck, we've got this! 🚀
